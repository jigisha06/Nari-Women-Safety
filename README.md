Nari – Women Safety Application

Nari is a women safety-focused application designed to provide quick assistance, emergency alerts, and real-time safety features to ensure security and confidence for women in critical situations.

 Features
🆘 Emergency SOS Button
Instantly sends alert to emergency contacts with location.
📍 Live Location Tracking
Share real-time location with trusted contacts.
🔔 Fake Call Feature
Simulate an incoming call to escape uncomfortable situations.
🚨 Nearby Help & Safe Zones
Locate nearby police stations, hospitals, or safe areas.
👥 Trusted Contacts Integration
Add family/friends for quick emergency communication.
📢 Alert Notifications
Sends SMS / app notifications during emergencies.

📱 How It Works
User opens the app
In emergency → clicks SOS button

App:
Sends location 📍
Notifies emergency contacts 📲
Additional safety features like fake call & nearby help assist user

 Objective
To create a reliable, fast, and easy-to-use safety system that empowers women and provides immediate help in emergency situations.
